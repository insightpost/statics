# 核心原则：画面内容说清楚，画面美学说具体

原文建议：用**连贯的自然语言**描述主体、行为、环境等画面内容，用**简短、明确的词语**描述风格、色彩、光影、构图等画面美学。有明确应用场景时，写出图像用途和类型；需要生成文字时，将准确的文字内容放在中文引号 “” 中。

可以记住两句话：



* **文生图：说清楚要画什么，再说明要怎样呈现。**

* **编辑图：说清楚改什么、改成什么，以及哪些内容要保留。**

## 从关键词堆砌改为画面描述

原文对比示例：

不推荐：



```
一个女孩，撑伞，林荫街道，油画般的细腻笔触使画面生动美好。
```

更推荐：



```
一个女孩穿着华丽的服装，撑着遮阳伞走在林荫道上，莫奈油画风格。
```

区别在于：后者明确了人物、服装、动作和环境之间的关系，并用具体风格词替代泛泛的美感描述。

# 文生图：一套通用提示词结构

## 整理模板

根据原文的「画面内容＋画面美学＋应用用途＋文字要求」归纳：



```
生成一张用于【用途】的【图像类型】。
【主体及关键特征】正在【动作或状态】，位于【环境与背景】。
采用【风格】，使用【色彩】与【光影】；【构图、视角或景别】。
画面中的文字为“【准确文案】”，放在【位置】。
【必要的画幅或保留要求】。
```

\*\* 不需要每次填满全部字段。\*\* 没有文字就删掉文字要求；简单画面可以压缩成一两句话。字段是查漏工具，不是必须照搬的固定语法。

## 各部分怎么写



* **用途与类型**：PPT 封面背景、电商主图、活动海报、儿童绘本插图、角色设定图等。原文建议明确用途，以提升场景适配度。

* **主体**：交代谁或什么是画面中心，以及影响辨识的外形、服装、配色、材质等特征。

* **动作与状态**：用具体动作替代模糊评价，例如「撑伞走在街上」「猫正在闻储粮罐」「坐在飞机上看向窗外」。这些关系写法在原文示例中均有体现。

* **环境与背景**：说明主体在哪里，以及与周围元素的关系。

* **画面美学**：按需选择风格、色彩、光影、构图、视角、景别和材质，不必全部堆上。

* **文字与规格**：准确写出文字内容；需要明确画幅时写出比例。原文包含带文字和指定画幅的示例。

## 改写示例：PPT 封面背景



```
生成一张用于技术分享 PPT 封面的横版背景图。
一座现代城市位于画面右侧，抽象的数据光带沿建筑之间延伸。
商务简约风格，蓝白配色，柔和光线，远景。
左侧保留干净的留白用于后续放置标题，画面不生成文字，画幅 16:9。
```

这个例子把「用途」「主体位置」「美学」「留白」「是否生成文字」分别交代清楚。

# 单图编辑：变化动作＋变化对象＋变化特征

原文给出的编辑公式是：**变化动作＋变化对象＋变化特征**，例如「将骑士的头盔变为金色」。常见动作包括移除、添加、替换、参考；对象可以是主体、背景、光影、色彩等。

## 整理模板



```
将【明确对象或区域】的【属性】改为【目标特征】。
保留【不希望改变的内容】。
```

对简单编辑，可以直接使用原文中的短指令；当对象容易混淆，或有重要特征不能变化时，再补充范围和保留要求。原文明确建议用参考图保持角色形象、产品信息或风格等特征的一致性。

## 常见编辑写法

以下为对原文编辑类别与指令的归纳：



* **添加元素**：给【对象】增加【元素】。

* **删除元素**：去除画面中的【明确元素】。

* **替换元素**：将画面中的【原对象】改为【新对象】。

* **改变风格**：将画面改为【目标风格】。

* **改变光影或色调**：将画面光影改为【光线效果】；将画面色调改为【目标色调】。

* **改变视角或景别**：将视角改为【目标视角】；将景别改为【目标景别】。

* **改变材质或背景**：将【对象】的材质改为【材质】；将背景改为【目标环境】。

* **人像编辑**：将发型、服装、表情或动作改为【目标特征】。

* **海报编辑**：修改标题字体、排版、文字内容、文字颜色或文字材质。

* **清晰度与修复**：将画面变高清；修复老照片。

## 改写示例：只换商品背景



```
将图片中储粮罐的背景改为温馨明亮的客厅一角，一只猫正在闻储粮罐。
保留储粮罐的外形、配色、标签内容和主体比例。
让商品与新背景的光照和阴影自然协调。
```

## 改写示例：只改变材质



```
将图片中椅子的材质改为浅色木材。
保持椅子的结构、形状、位置和画面构图不变。
```

**实践建议**：局部编辑优先描述变化本身，避免重新叙述整张图并引入无关细节；需要保留的内容写得具体，比笼统说「其他不变」更便于核对。


```
将绿框内的标题字体改为圆润可爱的字体，标题文字内容不变。
完成后去掉绿色框线，保留其他版式与装饰元素。
```



```
在图1蓝色涂抹区域增加图2中的斜挎包。
```

**实践建议**：上传标记图时，明确说明标记是操作提示，不是希望保留在成品中的视觉元素。

# 多图参考：每张图只承担明确的角色

原文强调：上传多张参考图时，要明确不同图片需参考或编辑的元素。例如「将图 1 中的角色放入图 2 的背景中，参考图 3 的风格进行生成」。

## 整理模板



```
图1提供【主体／角色／商品外观】。
图2提供【背景／场景／服装／材质】。
图3提供【风格／色调／排版】。
将【指定主体】放入【指定场景】，参考【指定视觉特征】生成。
保留【主体的关键特征】，不要引入【不需要参考的元素】。
```

## 原文中的典型操作



* **主体替换**：将图 1 的主体替换为图 2 的主体。

* **服装替换**：将图 1 的服装换为图 2 的服装。

* **场景合成**：把图 1、图 2 的元素合理放置在图 3 的场景中。

* **风格迁移**：参考图 2，将图 1 做风格转绘。

* **色调迁移**：将图 1 的画面色调替换为图 2 的色调。

* **材质替换**：将图 1 中的指定对象变成参考图 2 的材质。

* **文字或排版参考**：将图 2 的文字添加到图 1 中，或参考图 2 的标题颜色修改图 1 的指定文字。

## 改写示例：角色＋场景＋风格



```
图1提供角色形象，图2提供森林场景，图3提供绘本画风。
让图1中的角色在图2的森林小路上奔跑，采用图3的柔和绘本风格。
保持图1角色的脸部特征、服装配色和体型，不使用图3中的人物。
```

**实践建议**：不要只写「参考这些图片」。明确借用的是身份、构图、材质还是色调，避免把某张图的全部内容都带入结果。

# 风格与美学词汇：按维度选择，不盲目堆砌

原文提供了风格响应词典，涵盖热门风格、美学、摄影、潮流、艺术、材质等类别；下列为其中部分词汇的摘选，不是完整词典。

## 风格与艺术



* **摄影方向**：纪实摄影、城市摄影、人文摄影、街头摄影、胶片、CCD、单色摄影。

* **艺术方向**：工笔风、浮世绘、印象派、巴洛克风格、拼贴艺术、立体主义、超写实主义。

* **潮流与造型**：Riso、故障风、赛博朋克、蒸汽朋克、美式复古、Q 版、分格漫画、定格动画。

## 色彩与光影



* **色彩**：暖色调、冷色调、高饱和、低饱和、低对比度。

* **光影**：侧光、侧逆光、窗光、轮廓光、硬光、丁达尔光。

* **原文中的英文词**：`soft lighting`、`backlighting`、`top lighting`、`high-contrast`。

## 视角、景别与构图



* **视角**：鸟瞰、低角度视角、侧面视角、四分之三侧面。

* **景别与空间效果**：特写、近景、中景、远景、浅景深、深景深、动态模糊。

* **构图与英文词**：居中构图、`high-angle shot`、`full body shot`、`back view`、`enclosed composition`。

## 材质



* **柔软或纤维质感**：亚麻布、毛绒、皮革、薄纱、羊毛、`velvet`、`felt`。

* **塑形或透明材质**：树脂、粘土、超轻粘土、塑料、亚克力、玻璃。

* **硬质材料**：木头、大理石、陶瓷、石膏、金属、混凝土。

原文建议专业词汇使用词源语言，以提高响应准确度。这里不必把整段提示词翻译成英文，可以保留中文画面叙述，并按需加入明确的专业术语。

**实践建议**：先确定一个主风格，再选择少量与之协调的色彩、光影和构图词。不要同时要求互相矛盾的属性，例如同一区域既「高饱和」又「低饱和」，或同一镜头既「特写」又「全身远景」。

# 迭代与交付前检查

本节为实践补充，用于把原文写法转化为可执行的检查流程，不是原文给出的性能结论。

## 一个低成本的迭代顺序



1. **先确定内容**：用途、主体、动作、环境是否清楚。

2. **再确定美学**：主风格、色彩、光影、构图是否协调。

3. **补齐精确要求**：文字、参考图分工、保留内容、张数、画幅。

4. **针对偏差修改**：优先改最影响结果的一项，不同时重写所有要求。

5. **核对成品**：文字准确性、主体一致性、数量、画幅和用途适配。

## 常见偏差与修改方向



* **主体正确但场景不符**：补充主体与环境的空间关系，不只列环境名称。

* **局部编辑改变了整张图**：明确修改区域，并列出要保留的主体、背景或构图。

* **多图参考发生混用**：逐张指定用途，写清只参考哪些特征。

* **角色或商品变样**：补充实际参考图，明确要保留的身份或商品特征。

* **文字多写、错写**：把准确文案放入 “” 中，分别指定位置，并说明是否允许额外文字。

* **组图不统一**：先列共同要求，再逐张列变化，不把不同图片的要求混写在一起。

* **结果风格混杂**：减少风格词，保留一个主风格和少量辅助特征。

## 不要把视觉生成当作精确计算或工程交付

原文展示了图表、公式、地图、UI 初稿和包装效果等应用场景。对这些场景，建议额外注意：



* **数据图表**：真实数据、比例、坐标轴与标签必须核验；需要精确表达时优先用确定性绘图工具。

* **公式和知识图**：核对符号、文字与知识内容，不把生成图当作事实来源。

* **UI、包装与工业设计**：生成效果图不等于可运行界面、生产文件或可制造的结构设计。

* **真人、品牌与素材**：使用拥有合法使用权限的参考素材；对外发布前确认肖像、标识和版权使用范围。

